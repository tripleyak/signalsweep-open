# Security

Do not open public issues with API keys, cookies, OAuth tokens, private customer data, or account screenshots.

SignalSweep Open is designed as a bring-your-own-keys package:

- no shared credentials are included
- paid and Deep Research tiers are disabled by default
- browser-cookie extraction is off by default
- persistence and operator automation are excluded from this public package

If you discover a credential exposure or security problem, report it privately to the repository owner through GitHub before posting details publicly.
